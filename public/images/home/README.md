# Homepage image assets

Drop the approved homepage images in this folder using these filenames:

- `hero.jpg` — main homepage hero
- `about-finished.jpg` — finished lighting image used in About INLIGHT
- `about-technical.jpg` — technical/manufacturing layer used in the cursor reveal
- `difference-quality.jpg` — Quality over quantity hover preview
- `difference-supply-chain.jpg` — Global supply chain hover preview
- `difference-expertise.jpg` — Industry expertise hover preview
- `difference-manufacturing.jpg` — End-to-end manufacturing hover preview
- `work-01.jpg` — Selected Work project 1
- `work-02.jpg` — Selected Work project 2
- `work-03.jpg` — Selected Work project 3 / optional Our Standard reuse
- `standard.jpg` — optional dedicated Our Standard image

Recommended formats: `.jpg` or `.webp` for photography. Keep source images high resolution; we can optimize them later.

The site can keep using the existing remote images until these files are added, then we can switch the React image map to `/images/home/...` in one pass.
