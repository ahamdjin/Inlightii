# INLIGHT International — V1

A spacious editorial redesign concept for INLIGHT International, built with Vite + React + TypeScript.

## Direction

- Full-height sections with deliberate breathing room
- Warm ivory / near-black luxury palette
- Large project photography using INLIGHT's existing site imagery
- Subtle GSAP + ScrollTrigger motion
- Lenis smooth scrolling
- CSS-first hover micro-interactions
- Sticky "From idea to object" storytelling section
- Responsive behavior and reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

## Production check

```bash
npm run build
```

This is the first visual direction. Content, imagery, project ordering and section choreography are intentionally easy to iterate from here.
